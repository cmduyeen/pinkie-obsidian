### ✨ Kawaii Highlights

- 🌸 **Pill-shaped Pastel Tags**: Tags rendered as soft pill badges (`border-radius: 9999px`) that elevate gently on hover.
- 💖 **Cute Task Checkboxes**: Rounded checkboxes with soft strawberry accents.
- 📑 **Cozy Rounded Callouts**: Note callouts styled with delicate 12px rounded borders and subtle rose shadows.
- 🌿 **Ergonomic Reading Experience**: Calming contrast protects eyes during long research and writing sessions.
- 🎀 **Delicate Pink Scrollbars**: Slim, rounded scrollbars in pastel blush tones.

### 📦 Installation

#### Quick Manual Install:
1. Download [`Pinkie-for-Obsidian.zip`](Pinkie-for-Obsidian.zip) (or extract `theme.css` and `manifest.json`).
2. In your Obsidian vault, navigate to `.obsidian/themes/`.
3. Create a folder named `Pinkie` and place `theme.css` and `manifest.json` inside it.
4. Open **Obsidian** -> **Settings** -> **Appearance** -> **Themes** -> Select **Pinkie**.
